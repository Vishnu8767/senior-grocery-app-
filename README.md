# 🛒 ElderCart - Senior-Friendly Grocery App

A professional, highly accessible online grocery shopping interface designed specifically for senior citizens. 

## ✨ Key Accessibility Features
* **Large Typography:** Minimum 18px font size for readability.
* **High Contrast:** Clear color distinctions to aid visually impaired users.
* **Voice Search Prominence:** Large microphone icon for hands-free searching.
* **Simple Navigation:** No complex hidden menus or small dropdowns.
* **Help Button:** Always visible emergency/support contact button.

## 🚀 How to Run
1. Clone this repository: `git clone https://github.com/yourusername/senior-grocery-app.git`
2. Open `index.html` in any web browser.
3. No build tools required for the MVP!
